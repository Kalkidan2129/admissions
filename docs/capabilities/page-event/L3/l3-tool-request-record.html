Scope: what it must never touch

!
The tool must never touch:
  • IP address, user agent, fingerprint, email, name, lead ID or full page URL
  • Any table, for writing: it writes nothing
  • Messages, or anything a visitor sees

What the tool takes, and what stays with a person

The tool
  • Fetches the visitor's page events and saved interest tags
  • Lists the pages
  • Applies the 4 page rules
A person
  • Makes every judgment call
  • Decides whether to act on the answer
  • Approves each run before it takes effect (Taiwo Oludimimu)
