"Anonymised by design. anon_id is a keyed HMAC of the visitor id, stable within this surface and not reversible to a visitor; it rotates if the signing secret rotates, so nothing should be joined on it across a rotation. page_path and page_title are returned in place of page_url, which carries the query string the tracker writes an email into. page_title is null when the event recorded none, never an empty string, because the capability this serves is measured on fabricating no titles."

How it was kept honest

  • One pull onlyOne GET per page load. A finished pull is reused, and it is never pulled again with a bigger limit.
  • No joining on anon_idEach visitor is matched only to the events nested inside it in the same response; anon_id is never a join key, within a pull or across pulls.
  • Missing titles shown as "(no title)"A null page_title is never filled in from page_path or anything else.
  • Summaries built without AIPlain code builds each summary from the visitor's own events and checks it separately against those events.
