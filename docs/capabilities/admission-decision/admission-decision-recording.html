How the human gate is enforced

  • Six decision verbs, and nothing elseThe request schema accepts only approve, approve_with_conditions, reject, waitlist, request_information, schedule_human_follow_up, and rejects unknown fields (backend/src/routes/admin/internshipRoutes.ts:71-87). Each maps to a state in REVIEWER_DECISIONS (internshipStateMachine.ts:307-314). The route is POST /api/admin/internship/applications/:id/decide, behind requireSection('internship') (internshipRoutes.ts:651).
  • Reason codes from a closed listThe schema allows only a code in REASON_CODES (internshipRoutes.ts:80-83; list built at internshipReasonCodes.ts:192 from REASON_DEFINITIONS at :63). decide() refuses an unknown code, a code that does not apply to the decision, and a code that needs a message when none was written (internshipDecisionService.ts:109-126; rule at internshipReasonCodes.ts:210).
  • No override, force or isAdmin parametercanTransition(from, to, actor) takes exactly three arguments and allows a move only if the table lists that actor on that edge (internshipStateMachine.ts:264-279). decide() always passes actor: 'reviewer' (internshipDecisionService.ts:166-171). The system actor, which an AI recommendation authenticates as, is listed on none of the 11 edges above (internshipStateMachine.ts:20-29).
  • decided_by comes from the session, never the requestdecided_by is a required column (backend/src/models/InternshipDecision.ts:64). The route takes it from the signed-in token's email or subject, not the body (internshipRoutes.ts:658-663), and decide() writes it (internshipDecisionService.ts:182). If the token carries neither, the value recorded is the literal 'unknown-admin' (internshipRoutes.ts:663).
